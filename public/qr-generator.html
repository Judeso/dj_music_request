📋 Instructions d'utilisation

  1. Sélectionnez l'événement pour lequel vous voulez créer un QR code
  2. Optionnellement, entrez une URL personnalisée (sinon l'URL par défaut sera utilisée)
  3. Cliquez sur "Générer le QR Code"
  4. Téléchargez le QR code et affichez-le à votre événement
  5. Les participants scannent le code pour accéder directement au formulaire de demande

💡 Astuce : Imprimez le QR code sur des supports visibles (affiches, tables, écrans) pour faciliter l'accès des participants.
